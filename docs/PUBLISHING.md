## 已整理

- 中英文 README：面向使用者介绍产品、安装方式、数据去向和反馈入口。
- 中英文隐私说明和权限用途，包含当前同步默认值、网页脚本范围和网络请求。
- “关于”页：源码、隐私说明、权限用途、问题反馈和第三方声明入口。

这些说明根据仓库当前代码整理，不能视为完整安全审计或对现有商店版本的核验。

## Chrome 商店后台操作

1. 以最终发布包的行为填写单一用途、权限理由与数据披露，确保与 PRIVACY.md 一致。注意网页访问、浏览历史、搜索关键词、同步配置及在线资源请求的实际范围。
2. 填写无需登录即可访问的隐私政策地址，并从未登录的浏览器检查链接。
3. 更新商店描述和截图，使其与扩展当前功能及默认设置一致。
4. 本地验证书签/历史权限允许与拒绝、网站访问限制、截图、同步开关和关键词清除。
5. 确保版本号对应最终源码，再构建并上传；发布后记录商店版本、源码提交及版本标签，在更新记录中说明用户可感知的变化。不要给未核实的历史版本补造对应关系。
